- When you set `expect` on a piped bash command, add `set -o pipefail`; otherwise the exit status is the last command's (for example `tail`), and the surprise report is wrong. With `pipefail`, a count pipeline whose first command finds nothing (`pgrep … | wc -l`) exits 1 although it printed 0.
- After `update_notebook` supersedes a learning, the notebook no longer knows the old id; use and retire the new one.
- Retire notebook learnings in one call and wait for it before `ledger_status` `done`; in the same parallel batch, the ledger-close hold still sees them open.
- Vitest in this repo hides `console.log` from passing tests. To inspect values in a scratch test, write them to a temporary file and read it, or assert on them.
- Faux-session compaction (`tests/helpers/faux-session.ts`) needs `session.settingsManager.applyOverrides({ compaction: { keepRecentTokens: 1 } })`, or it reports "Nothing to compact".
- For exact upstream Pi API or release facts, fetch the tagged file from `raw.githubusercontent.com` (for example with `pi_exec` `fetch`) and read it; search summaries can be truncated or secondhand.
- Test fakes of `ExtensionToolContext` need `tools` and `executeTool`; `ctx.executeTool()` also needs an assistant message that issued the parent call, so drive nested calls through a real faux-model turn.
- Before you say a reference project lacks a feature, check its ADRs, specs, and tool contract, not only its README.
- Apple-pi is self-contained: design as if skills and tools installed outside the repo (such as `~/.agents/skills`) do not exist. Borrow their ideas only when they serve the user's goal.
- When a design choice confuses the user, restate the options with a small concrete example, such as the tool-call JSON and what the server then does.
- In `edit` oldText and newText, write non-ASCII characters (·, −, ↵) literally. A `\uXXXX` escape stays literal text, does not match, and fails the whole edit batch.
- To start a long-lived server and poll it in the same bash call, run it as `(cmd > log 2>&1 &)`; a plain trailing `&` keeps the call attached until it times out. For longer waits, use `run_in_background`.
- There is no tsx, jiti, or vite-node here. To run one-off TypeScript against repo sources, write a temporary `*.test.ts` in a Vitest-included directory, run `npx vitest run <file>`, and delete it before the full suite. Keep checks that wait for a human or browser outside the test tree; copy them in only to run them, and remove the copy in the same command after `;` (a leftover copy hangs the suite).
- For browser visual checks, run `uv run -q -w playwright python` with `p.chromium.launch(executable_path="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome")`. Wait for a rendered selector before key presses, take screenshots with `animations="disabled"`, and collect `pageerror` and console errors.
- After Biome formats a file you wrote, read its current lines before an exact-text `edit`; text copied from your own earlier payload no longer matches.
- Stage commits by explicit paths, not from a filtered `git status`: a filter that hid another lane's `tests/ledger-` files also hid my own `components/.../tests/ledger-review.test.ts`.
- If the full `npm test` times out in `components/tasks` or `pi-exec-work-panel`, rerun that file alone before you treat it as a regression; these tests are flaky under full-suite load.
- `git rm` stages deletions at once, so they ride along in the next commit even when you stage by explicit paths. Delete with plain `rm` and stage the deletion with the commit it belongs to; check `git show --stat HEAD` after each commit.
- To test tmux behaviour without touching the operator's server, use `tmux -L <name> -f /dev/null new-session -d -x W -y H`, attach a client through a Python `pty.fork()` running `tmux -L <name> attach` when hooks need one, and screenshot panes from `capture-pane -e -p` through Rich `Text.from_ansi` -> `save_svg` -> Playwright. Avoid `window-size manual` there (tmux 3.5a crashes on `new-window`), and set `PI_TMUX_STATE_DIR` to a temporary directory: the agent records in `~/.pi/agent/state/tmux-sessions` are shared across tmux servers and a scratch sidebar can prune them.
- Check a tmux binding with `tmux list-keys -T prefix <key>` before telling the operator it exists.
