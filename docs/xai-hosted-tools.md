# xAI hosted tools

Every ordinary agent request that uses xAI through Pi's `openai-responses` API receives xAI's built-in `{ type: "web_search" }` and `{ type: "x_search" }` tools unless the payload already includes that tool. Pi's internal compaction and branch-summary calls use the raw stream outside `before_provider_request`, so the extension does not add hosted tools to summarization. Completions-routed Grok models are left unchanged: switch those models to `openai-responses` against `https://api.x.ai/v1` if they should search. Domain filters, handle filters, and image-search flags are not configured; xAI bills each tool when the model uses it.
