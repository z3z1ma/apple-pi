# Prioritization

Make a credible choice about work and its opportunity cost. Read and follow the [shared process conventions](../handbook-writing/references/processes.md).

The authorized portfolio or product owner chairs with affected delivery owners. A `product-manager` owns product priorities; `director-of-engineering` resolves cross-team delivery commitments. Use `vp-of-product` for value challenge and `infrastructure-cfo` when cost or lock-in is decisive.

1. **Establish the choice set.** Gather requested outcomes, existing commitments, dependencies, uncertainty and consequences of delay. Use existing tasks and inspection when available; a current work list is not evidence that every useful opportunity has already been recorded.
2. **Compare feasible choices.** Include continuing existing work and doing less. Ask owners about actual capacity and what each choice displaces. Keep unknown value or effort unknown; use economic scenarios only when their premises are genuinely comparable.
3. **Commit within authority.** State what is accepted, deferred or stopped, why, and what evidence would change the order. Authorized managers settle assignments and affected owners confirm changed commitments. A priority label alone assigns no work and cancels nothing.

Done is an actionable set of priorities with explicit trade-offs, owners and revisit conditions. Preserve unfinished work and record uncertainty instead of presenting a computed ranking as the decision.
