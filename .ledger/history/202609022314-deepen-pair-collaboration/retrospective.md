# Retrospective

## What Mattered

The strongest pair behavior came from a clear navigator frame plus a narrow communication interface, not from more navigation tools or a long behavioral checklist. Questions belong in the existing peer channel and deserve the same transactional and stale-confirmation guarantees as findings.

## Learnings

Pi already carries image blocks through normal tool results, so image support required preserving user images behind source-bound receipts rather than adding filesystem access. Recent-request data is also consumed by consultant context; changing that projection required updating the shared consumer. Known-note recall must return visual sources too, or compaction makes older image evidence unreachable.

## Improvements

When changing a shared projection type, search all production consumers before deleting compatibility fields. Keep pair-specific tool guidance separate from generic root guidance so unavailable tools are never suggested.
