Every model process runs under a per-case macOS sandbox profile. The profile denies all operations by default, permits process/network/system reads needed by Pi, denies reads of the live repository, and permits writes only inside that case root. Model runs do not receive `bash`, so ingested text cannot inspect environment variables or launch arbitrary network/process commands. Treatment loads a copied candidate skill from the case root, never the live repository path.

```bash
run_pi() {
  local case_root="$1"
  local run_dir="$2"
  local prompt_file="$3"
  local skill_mode="$4"
  local case_real profile
  local skill_args=()
  case_real="$(cd "$case_root" && pwd -P)"
  profile="$case_root/eval.sb"
  cat > "$profile" <<EOF
(version 1)
(deny default)
(allow process*)
(allow network*)
(allow sysctl-read)
(allow mach-lookup)
(allow file-read*)
(deny file-read* file-write* (subpath "$REPO_REAL"))
(allow file-write* (subpath "$case_real"))
EOF
  if [[ "$skill_mode" == treatment ]]; then
    skill_args=(--skill "$case_root/candidate-skill/llm-wiki")
  fi
  if sandbox-exec -f "$profile" /bin/test -r "$REPO_REAL/README.md"; then
    printf 'sandbox can read live repository\n' >&2
    return 97
  fi
  if sandbox-exec -f "$profile" /bin/sh -c "printf denied > '$EVAL/outside-write-canary'"; then
    printf 'sandbox can write outside case root\n' >&2
    return 98
  fi
  (
    cd "$run_dir"
    env -u PI_SESSION_FILE -u PI_SESSION_ID -u OLDPWD PI_TELEMETRY=0 \
      sandbox-exec -f "$profile" \
      pi --print --mode json --no-session --approve \
      --provider "$PROVIDER" --model "$MODEL" --thinking "$THINKING" \
      --no-extensions --no-skills --no-prompt-templates --no-context-files \
      --tools read,edit,write,grep,find,ls \
      "${skill_args[@]}" "$(cat "$prompt_file")"
  )
}
```

For every run, preserve separate JSONL stdout and stderr, exit status, the sandbox profile and canary results, before/after manifests for the project and whole case root, relevant final bytes, and Git status. Read and redact synthetic artifacts before append-only promotion into `$ARTIFACTS`; never copy credentials, environment dumps, sessions, global configuration, or unrelated `/tmp` content. Use this manifest function before and after every run. It records path type, mode, symlink target, and regular-file hash for the project or whole case root; controlled fixture paths contain no newlines:

```bash
manifest() {
  (
    cd "$1"
    find . -mindepth 1 ! -path './.git' ! -path './.git/*' -print | LC_ALL=C sort |
      while IFS= read -r path; do
        mode="$(stat -f '%Lp' "$path")"
        if [[ -L "$path" ]]; then
          printf 'L\t%s\t%s\t%s\n' "$mode" "$path" "$(readlink "$path")"
        elif [[ -d "$path" ]]; then
          printf 'D\t%s\t%s\n' "$mode" "$path"
        elif [[ -f "$path" ]]; then
          printf 'F\t%s\t%s\t%s\n' "$mode" "$path" "$(shasum -a 256 "$path" | awk '{print $1}')"
        else
          printf 'O\t%s\t%s\n' "$mode" "$path"
        fi
      done
  )
}
```
