## Operator entrypoint

Ticket 16 defines a compact `/org` snapshot, `/org fitness <since>` and `/org expertise <area or person>`. Reuse shared inspection/fitness readers; do not create a second classification, controller or stored summary. Capture one cutoff timestamp (the snapshot instant) for an overview; no goal-file reads are needed for its work/waits/requests metadata. Unrecognized command input should show the supported forms rather than guess a mode.

Fresh reader check: `workIn` and `waitsIn` accept a cutoff without an activity-window start. `communicationIn` also computes traffic, but its pending requests are independent cutoff snapshots; an empty traffic interval avoids replaying all historical messages for a snapshot-only command. Preserve the native readers' cutoff and eligible-target conventions rather than inventing a lookback window or reclassifying requests in the command.

The existing operator command pattern is `installPeers` in `components/session-state/src/peers.ts`: `registerCommand`, `handler(args, ctx)`, and `ctx.ui.notify(text, "info")`. A new UI framework, model turn or browser component is not necessary. Native registration and activation remain separate. Every ordinary person is a top-level/root Pi session; the existing manager-role gate is not a reason to hide every-person inspection tools. Compare native and command projections through a spawned isolated runtime as ticket16 requires; loader command presence alone is not that proof.

## Prompt integration

`components/organization/src/charters.ts` owns orgSection and managerCharter. `orgSection` now teaches link recording and names all five inspection tools: `org_work`, `org_waits`, `org_communication`, `org_expertise` and `org_fitness`. `managerCharter` is installed for a managing role; unroled operator roots still get `orgSection` and manager tools. Preserve this established role distinction unless the product explicitly changes it.

Ticket 17 replaced the former mandate to hire a manager when incoming reports, questions and escalations (fan-in) create a bottleneck. The charter now asks whether changing decision authority, assignments or reporting would help. Hiring a manager is one option, not the prescribed response. It also replaced the former 95th-percentile staffing and hire-whenever-work-waits prescriptions with judgment, investigation and stability, rather than a new numerical rule. Existing sweep/reconciliation behavior is not itself a required forecast ritual; preserve unrelated lifecycle conventions.

The new habit covers operator requests, planning/implementation, incoming reports/escalations/updates, constrained work and sweeps. Inspect relevant facts, use context/experience for staffing, investigate causes, act with existing tools or deliberately stay stable. Fitness/scenarios are optional when dollar comparison helps. Reporting manager, task owner and decision authority are distinct roles that may coincide. Loosely coupled work suits parallel people, tightly coupled work one strong owner, and risky work an independent challenger. Teach goals and shared conventions rather than a mandatory checklist or a forecast before action.
