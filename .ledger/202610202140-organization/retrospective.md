## Learnings

 before `${...}` inside a template literal in a Node edit script is swallowed twice (the script's own template and the payload's); write such lines with the Edit tool.
- Re-serializing a theme manifest with `JSON.stringify(json, null, 2)` reflows every array; splice new keys into the text instead.

## Improvements

- The docs catalog table is generated by hand; a test could compare it with the role files so it cannot drift.
- Agent World's team rooms reuse the wing painting and label ("Mara wing"); a theme word for a team room would read better.
- The runtime could tell a bridge that its process started before a migration, so the operator learns to restart it instead of seeing null columns.
