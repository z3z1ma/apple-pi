# Rubric

Score each surface 0 (broken) to 3 (indistinguishable from the reference) on each line. Anything below 3 is a finding.

## Visual

- **Alignment.** Edges, baselines and centres line up across neighbouring regions; no stray offsets.
- **Spacing scale.** 4/8-based rhythm; equal things have equal gaps; no cramped or loose outliers.
- **Type scale.** A small set of sizes and weights used consistently (title, body, meta, label).
- **Colour.** Semantic tokens only; one primary action colour; muted meta; contrast readable in both themes.
- **Controls.** Buttons, inputs and selects share heights per density (24/28/32); icon buttons square; consistent radius.
- **States.** Hover, focus-visible, selected, disabled, empty, loading, error and overflow all designed.
- **Density.** Information per pixel comparable to the reference without crowding.
- **Responsiveness.** 1440, 1100 and 900 wide; nothing clipped, overlapping or orphaned.

## Interaction

- **Steps.** Clicks/keys for the common task; compared with the reference.
- **Attention.** What the operator must notice, read or decide; what could be summarised, batched or delegated.
- **Keyboard.** Every common action reachable without the mouse; shortcuts discoverable.
- **Feedback.** Every action acknowledges at once; outcomes are visible without hunting.
- **Recovery.** Mistakes are reversible or confirmed; drafts and selections survive.
- **Robustness.** Long text, many items, slow or failed loads, runtime restarts, and concurrent changes behave.
