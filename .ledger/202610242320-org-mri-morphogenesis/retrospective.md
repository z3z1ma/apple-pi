## Learnings

- Preserve expressive concepts while cutting implementation machinery. The operator accepted the brief's intent, not every proposed engine or workflow. The later observability direction sharpened this: expose facts cheaply and let managers judge; fitness and scenarios are instruments, not required rituals. Historical database contents describe the system that produced them, not necessarily today's runtime.
- Before specifying a historical metric, trace each input to its durable producer. `needs_you_since` is mutable current state, not an attention-duration history; prompt events measure a different fact. Check that adjacent windows add up without charging accrued delay twice. Review later found the same class of error when current organizational roots were used to select past work: current ownership and membership at the event's time answer different questions.
- Use hours and parallel work in agent-economic examples, not human-day assumptions. Express cost of delay per hour and choose horizons appropriate to the decision.
- Ask returning reviewers to read the revised file from disk, and check quoted lines against that version before acting. A cold reader reused a superseded specification and reported contradictions that no longer existed.
