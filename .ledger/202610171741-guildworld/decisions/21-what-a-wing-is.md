# What a wing is

## Question

What groups the coordinator's agents into the headquarters' wings, and what does a wing look like and do?

A wing was one per tmux session in [What Agent World abstracts in tmux and Pi](05-world-ontology-and-truth.md); [Purpose and form of the world](19-purpose-and-form-of-the-world.md) made places follow functions and reporting instead. Decide what a wing stands for (a project or repository, a ledger thread, a group working together, a tmux session, or something else), how many there can be, how the headquarters shows them per theme, and where a coordinator's dormant agents sit relative to their wing.

## Answer

Decided with the operator, 2026-10-18.

- **A wing is a repository or project.** Each repository the coordinator's agents work in has its own wing of the headquarters; an agent stands in the wing of the repository its session works in (its git context). Decor can follow the project.
- **Wings are remembered.** Once a repository has had an agent, its wing stays in the headquarters, closed up while it is empty, so the layout stays familiar. This is the first presentation state Agent World keeps for itself (which repositories have wings, and in what order); projection first still holds for everything else.
- **Dormant agents leave their wing** and rest in the dormant place (inn rooms, nap pods, infirmary); a wing shows only awake agents.
- **No repository:** an agent working outside any repository (a scratch directory) works in a shared common room of the headquarters.
- How the headquarters makes room for a growing number of wings belongs to [How places are built](15-how-places-are-built.md).
