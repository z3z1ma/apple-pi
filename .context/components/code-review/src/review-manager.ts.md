The panel reads with the current person's scope, but a confirmed interactive operation is an operator command. Enqueue explicitly assigns the current lasting person as owner; the UI is not the durable execution owner. Read failures stay visible and never start or migrate a runtime. Queue and selected detail share one SQLite read snapshot.

An uncertain send retains its original command ID and operation for exact replay while this extension/session context remains alive, including hide/reopen. The recovery map is not durable: session/context changes and reload clear it. The runtime journal and admitted review remain authoritative; a new capture is distinct from replay. Cancellation of a dialog or session context prevents later UI updates, not a claim that an already submitted runtime mutation was rolled back.

The entrypoint is not yet in the package activation list. Its shortcuts replace the old combined work panel when that surface is retired; both registrations must not be activated together.
