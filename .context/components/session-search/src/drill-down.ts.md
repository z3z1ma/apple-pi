## file

Exact recovery receives sources already filtered by recall scope. Stable entry windows are line-based over full rendered evidence; existing #N:path addresses recover attempted write/edit payloads by their content lines.

Why: a source ID does not override active-lineage selection, and serialized tool arguments can place many payload lines into one large rendered line. Line continuation is not a byte bound; the current contract deliberately adds no arbitrary quota or character-offset API.
