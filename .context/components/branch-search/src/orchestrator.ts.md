## symbol:SEARCH_BLOCKED_TOOLS

A search fork keeps the parent's tool declarations and identity for prefix reuse. Its extension tools still receive the parent's context: workplace actions would act as that live person, and interns would run from its directory rather than the candidate worktree. Keep these actions blocked when the workplace tool surface changes. `read_thread` also belongs here because reading consumes the person's unread marker.
Why: removing the old delegation tools left the replacement `hire`, mail, and intern tools executable inside a search attempt; the attempt could affect the organization outside its temporary worktree.
Coupled: components/shared/src/forked-continuation.ts, components/session-state/src/mail.ts, components/interns/src/index.ts
Verify: components/branch-search/tests/fork-tools.test.ts
