A maintenance envelope is the canonical coverage marker for every maintenance dimension, including an intentionally empty review.

Real context growth uses provider-reported usage. Automatic compaction keeps its separate raw source-entry clock because its setting counts ledger entries.
Why: only usage from an assistant that responded after a compaction is a valid post-compaction baseline. The last assistant before the anchor, and the usage stored on the compaction entry itself, still report the pre-compaction size. The compaction entry's usage is the summary call, not the new context. Growth is also undefined when no valid usage exists, or when the current context is smaller than the baseline, such as a mid-session model switch. Callers must fall back to the raw estimate. Measuring from zero would re-fire stages every turn. Clamping a stale baseline to zero would starve the stage.
