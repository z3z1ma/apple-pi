`rootOf` follows current recorded managers, using a permanent departure's last reporting snapshot only when the live row is absent. This applies to a missing anchor and to removed intermediate managers; a current row, including its null manager, wins. A supplied reporting map overrides current reporting, including explicit null, for prospective-move checks; missing map entries still resolve through current rows and departure evidence. A fully unknown next manager stops at the last known person, and a cycle across live or departed records throws. `taskOrganization` is the current root of the organization recorded on the task. `anchorsOf` is that organization plus every recorded task anchor whose current root is it.
Why: removing a merged former root must not strand its tasks, reviews or links. Retained reporting evidence preserves organizational authority without rewriting provenance or admitting a departed identity as a current person. A successor supersedes link grants no organizational authority; it can be authored outside the departure path. Independent departure with a null manager stays independent.
