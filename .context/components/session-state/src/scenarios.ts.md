`compareScenarios` and recorded predictions validate the same scenario and feed the existing `evaluate`; supplied start/outcome histories are manager premises, not a certified live snapshot. Canonical comparisons sort opaque IDs by exact string ordering, not locale collation, and include exact opportunity/task identities, valuations and starting histories, not names, organization descriptions or evidence order. Initial histories appear once and preserve already-closed state, including a close at zero that U counts in its half-open window.
Scenario outcomes omit U's unmodeled delay-state breakdown at both aggregate and contribution levels; assignments/waits are not supplied by this history shape. The actual arithmetic/components remain U's results.
Why: dropping initial obligations or re-closing completed work would improve a forecast by changing the premise rather than its outcomes; a second calculator or special endpoint credit rule would drift from realized fitness.
Relative `recording` origins bind to one captured preview time or immutable link creation; raw scenarios stay unchanged. Each resolved interval must have a finite advancing end, including the actual recorded window when an absolute scenario has a mismatched clock. Positive offsets can round back to a large origin; rejecting that is representability validation, not a fixed minimum horizon. Predictions observe `[created_at, created_at+horizonMs)` for their exact recorded target identity. Listing is strictly the caller root target plus existing historical link-origin admission; a prediction must have a message source, otherwise its raw row is unreadable evidence without restricting generic link writes; a later merge never aggregates former-root forecasts or substitutes a larger observation root. Fixed clock mismatch leaves expected and available observed totals visible, but no numerical error.
Why: replay timestamps and targets are forecast premises, not mutable bindings. Forecast error measures calibration, not causal attribution.
Valuation checks cover every opportunity, including unpursued work. Historical task ownership and retained non-null `opened_at <= recordedAt` are checked before goal access; anticipated/unmapped/missing/unvalued/not-yet-opened/foreign-at-recording identities are unverifiable. Structural ownership alone says nothing about task birth; a later task never upgrades an earlier prediction to verifiable. Opening ties are inclusive timestamps, not a shared event sequence. Numeric value or delay drift suppresses error; identity survives moves/archives and textual estimate attribution alone is not numeric drift. Genuine I/O/history failures stay errors outside per-row scenario parsing.
Observed total retains coverage/incomplete/exclusions/attention metadata; incomplete observed valuation suppresses numerical error, while static exclusions alone do not. Nonfinite observed totals are unavailable with explicit reason; derived calibration subtraction is checked separately even when both operands are finite. Coverage share overflow maps only the two nonrepresentable share fields to null with a separate metadata reason, without recomputing ratios or suppressing an otherwise finite error. All of this is adapter projection, not new U arithmetic.
Unreadable generic-link payloads retain raw data/reason independently. Generic links store valid JSON; this isolation does not promise recovery from corrupted SQLite values that existing realized-history readers also parse. No prediction or identity-binding state is persisted.
