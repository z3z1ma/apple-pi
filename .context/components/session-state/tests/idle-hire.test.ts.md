The manager calls the real typed hire tool through a faux-model session and isolated runtime. Workers are fixture processes that report hello and record commands, not paid models. Omitted and whitespace goals must produce no assignment/focus/task or startup steer; a supplied goal still produces its real task.md and ordinary startup steer. Task titles live in task.md, not a work_tasks.title column. Economic fields on an idle hire have no task to attach to and must stay out of command.goal.
Why: the public start payload and resulting work records are both part of this contract. A successful tool reply alone could hide a placeholder assignment or an automatic opening turn; a command-shape assertion alone could miss a runtime that creates work anyway.

Successful new lasting role hires, including idle ones, receive the current incarnation's positive started_at as hired_at. A failed idle launch retains its role/specialization but no date; subsequent call-in does not invent one. Existing hire-date tests separately cover historical rows and temporary peers. This suite proves the runtime emits no opening steer, not a universal work pause against later live mail or manual input.
