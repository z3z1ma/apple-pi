## file

The same observer consumes native Pi events from an in-process peer and a one-shot intern's JSON stream. Use the last assistant message to decide the outcome: a provider error that Pi successfully retries is not a terminal failure. Usage and file changes still cover the whole run.

Structured values come from a successful tool result's `details`, after tool-result hooks, rather than the model's proposed arguments. A later failed return clears an earlier value. The final result holds the complete operation history; intermediate progress is a replaceable snapshot and may be coalesced under socket backpressure.
