Two cancellation identities are the minimum for one completion to settle the old work while another remains suspended across new admission. This bound reproduces the found race; it is not a runtime request limit or an arbitrary-population theorem.
Why: a one-cancellation configuration cannot reach that interleaving and would make a superficially successful model run miss the discovered defect.

Deadlock checking is disabled because this configuration checks safety with no fairness/eventual-completion promise. Quiescence and blocked resource cleanup are allowed outcomes, not product deadlock findings.
