## file

Every fidget answers hover, a left click, and the right-click menu. The avatar walks up before the default play changes how it looks. An arrival between two reads is not an early play. None of it calls the backend. `window.calls` records every backend call by name. Clicks reach the world through the panels, which still draw for screenshots. `AGENT_WORLD_SHOTS` saves `aw-29-<theme>-<kind>-*.png`.
Why: a fidget that sent a command would no longer be presentation only.
