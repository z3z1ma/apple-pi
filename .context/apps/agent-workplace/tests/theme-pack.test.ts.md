## file

The pack check runs over the real packs and over copies of the fantasy pack with one fault each. Each fault is named by its file and what is wrong. Copying a whole pack is slow beside other headless suites. Fidget objects are optional; a pack without any passes, but a place that holds one is checked. With fewer pets, a quiet room may hold a single fidget.
Why: a missing optional fidget must not fail the pack, and a present one must not skip the check.
