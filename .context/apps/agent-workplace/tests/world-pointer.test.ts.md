## file

The world's cursor is the pack's hand, never the default arrow. It taps over something to do, is a fist over floor nobody can walk to, and points over open floor. A left click drops a yellow X where the avatar is heading, or a red X on what it acts on, gone within about half a second. Screenshots draw the hand where the pointer is because they leave the system cursor out. `AGENT_WORLD_SHOTS` saves `aw-alive-01-<theme>-*.png`.
Why: a default arrow or a marker that stays would hide which pack and which click the operator is using.
