## file

Instructions use the backend API in Node, without Electron, over a real session-state runtime and the real bridge. The stored entry replaces streamed text with the same words. A follow-up is held until the run settles and can still be withdrawn; ending the run without releasing it does not send it. A declined confirmation never reaches the runtime. Without a UI bound before the first prompt, `ask_user_question` drops itself at `before_agent_start`. Answering a question closes it in every view.
Why: a follow-up sent while still held would start a second turn, and an unbound UI would hide the questionnaire drop.
