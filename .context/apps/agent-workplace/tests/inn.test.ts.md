## file

Stopped sessions sleep at the inn with their last task. Waking one sends `start`, carried out in a scratch tmux server whose windows find a fake `pi` first on PATH. Ending a session sends `close`, confirmed only while it is busy. A window gets the PATH of the tmux client that opened it. Asleep people are in no awake place. `pi --session-id` reopens the same session. The new window opens right after the window the operator's client shows.
Why: the operator's tmux server and Pi must stay untouched, and a close of an idle session is not confirmed.
