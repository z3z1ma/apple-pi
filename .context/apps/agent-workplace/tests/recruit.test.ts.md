## file

Recruiting sends `start` for a new session in a scratch tmux server whose windows find a fake `pi` first on PATH. A worker opens after its coordinator's pane and reports to it. An independent agent opens after the operator's most recently active client and reports to nobody. A window gets the PATH of the tmux client that opened it. With no client attached, an independent agent has nowhere to open.
Why: the operator's tmux server and Pi must stay untouched, and an independent hire needs a visible client pane.
