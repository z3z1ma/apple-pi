## file

The forge uses the committed built world UI over a fixture that answers pull requests, diffs, the outside-write gate, and delegation, and records every call. Drafts lie a little faded. Pieces sit on workbench slots and are read on entering and again while the operator stays; leaving stops the reading. Comment and Request changes need words; Approve does not. Declining, including Escape, sends nothing and keeps the review page open. A confirmed write uses the token for exactly what was shown. `AGENT_WORLD_SHOTS` saves `aw-2x-*.png`.
Why: a reused token or a write on Escape would send a change the operator did not confirm.
