## symbol:WorkHistory

The team filter uses the task's recorded headquarters exactly, not today's reporting ancestry. A people filter selects actual assignment participants across organizations and labels the original anchor. Finishing an assignment is displayed separately from a task's done status; it is not proof that the whole task completed. Missing history in an older snapshot is distinguished from an empty known history. Compact disclosure retains every record without a result cap.

Task bodies mount only after an explicit Read task click. Reading registered task content is observation, not reading a thread/transcript; no seen or participation operation belongs here. Markdown uses the existing escaped renderer and explicit file/link bridge. Closing an expansion discards its pending read result through effect cleanup.
Why: moving a person must not rewrite which team did historical work, and merely browsing organizational metadata must not acknowledge conversations or fetch every task body.
