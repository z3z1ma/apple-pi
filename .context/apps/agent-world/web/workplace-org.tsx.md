## symbol:Org

Org keeps one plan and the actual world snapshot separate. A role position is a proposal, never a person; Start team returns actual session identities that are retained on every retry. Only explicit backend editable=true unlocks a rejected plan: a missing visible person alone cannot prove that no launch/goal/move was recorded.

Profile inspection hides rather than discards the plan. Chat/Mail keep this view mounted, while returning to World or reloading clears memory-only drafts. Immediate Add person is a separate ordinary recruit flow, not a one-position team plan. Its busy callback protects parent navigation from unmounting an in-flight request; after an uncertain result the form protects against blind resubmission.

Whole-team startup explicitly discloses operator pull membership before submission. Joining is not a read acknowledgment. Runtime remains authority for reporting/work safety; the UI sends the observed lasting branch and never changes the tree optimistically.

Native move confirmation owns focus and Escape; refusal appears inside that active dialog, not only in the inert background. The embedded shared profile resets position to static so narrow-screen profile styling cannot cover reporting controls.
