## file

Raw HTML renders as escaped text, http(s) links as `<a class="aw-md-link">` with no `target`, links to files (a path, or a `file:` URL) as the same anchor with `data-file`, a link of any other scheme as a dotted span titled with its target, and images as their alt text; the result goes into `dangerouslySetInnerHTML`. A `name:digits` href (`guide.md:12`) is a path with a line number, not a scheme.
Why: transcripts are untrusted (tool output, web pages the agent read); the window must never run script, navigate, or load remote content (its CSP allows only `self` and `data:`). A link opens only through the transcript's click handler, which prevents the default and asks the main process (`openLink`, or `openFile` with the agent's directory); the main process checks it again (`src/backend/links.ts`) before `shell.openExternal` or `shell.openPath`, and shows a file that could run (an execute bit, an app bundle, a script) in Finder instead of opening it.
