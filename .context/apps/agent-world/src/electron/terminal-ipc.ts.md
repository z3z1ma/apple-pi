## file

The terminal bridge accepts calls only from the application's current WebContents main frame. Shape guards are followed by explicit field construction, so renderer extras cannot select a shell, environment, executable or override an operation kind. Native process authority stays in the backend; nodeIntegration remains off in the renderer.

Committed full main-frame navigation, renderer death and actual window close release that renderer's owned terminals in main.ts. Attempted navigation is not a cleanup event: the existing native leave dialog may cancel it, in which case the shells remain alive.
Coupled: apps/agent-world/src/terminal.ts, apps/agent-world/src/backend/embedded-terminal.ts, apps/agent-world/src/electron/main.ts, apps/agent-world/src/electron/preload.ts
