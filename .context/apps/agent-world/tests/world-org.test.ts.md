These browser checks enter Org through the built World-to-Workplace link. The preload fixture replaces Electron's `window.agentWorld` bridge with in-memory responses. It holds reporting-change, team-start and direct-hire promises, emits startup progress separately, records immutable request copies, and explicitly publishes snapshots of the actual people and reporting lines. Keep those seams distinct: an accepted action or ready event alone does not prove that the live reporting tree changed.
Why: immediate success fixtures miss pending states and can hide duplicated starts, while request references changed by the UI could make an invalid retry look as though it preserved identities. Runtime/backend suites own authorization, task/channel preservation and kickoff idempotency; this fixture proves the operator controls and payloads, not those durable invariants.
The work fixture keeps a current Ada-team person on historical Daria tasks. Team history follows the recorded organization anchor, while person history includes that person's participation across teams. Snapshot metadata may be displayed and searched without any task-body or transcript read; the test records explicit task reads separately.
