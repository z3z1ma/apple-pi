These browser checks enter Org through the built World-to-Workplace link, using the explicit `?world` route because bare URLs now open Workplace Chat. Code/Issues fixtures cover that default entry. The preload fixture replaces Electron's `window.agentWorld` bridge with in-memory responses. It holds reporting-change, team-start and direct-hire promises, emits startup progress separately, records immutable request copies, and explicitly publishes snapshots of the actual people and reporting lines. Keep those seams distinct: an accepted action or ready event alone does not prove that the live reporting tree changed.
Why: immediate success fixtures miss pending states and can hide duplicated starts, while request references changed by the UI could make an invalid retry look as though it preserved identities. Runtime/backend suites own authorization, task/channel preservation and kickoff idempotency; this fixture proves the operator controls and payloads, not those durable invariants.
Retained setup coverage closes and resumes both unstarted and partial plans, cancels replacement, and compares the retry's complete request with the original plus recorded person tokens. This distinguishes retaining the visible goal from retaining the safe backend retry identity. Accepting replacement clears only the plan; snapshot people remain, and the fixture verifies that no close, move or recruit request followed.
Organization display names are device-local preferences. The browser scenario saves and reloads through the UI, verifies Cancel, then checks the relabelled channel sends its original stable ID only on explicit open. Separate rename, membership and channel-read traces catch accidental runtime mutation or acknowledgment during display-only edits.
Specialization is optional role focus: the fixture proves empty immediate-hire requests omit it, nonempty text is trimmed for submission, the retained draft keeps its text and locks it after startup, and recorded existing-person text is read-only.
The pinch check starts with an overflowing chart and scrolls away from its edges before measuring pointer anchoring. Normal scroll limits constrain anchoring when the chart fits. Send browser wheel input with Control held, observe default prevention at document bubbling, and compare visual viewport/device scale separately from the canvas transform; a synthetic event alone cannot prove that browser zoom was avoided. Ordinary wheel remains native scrolling.
Started plans fold immutable fields under Setup plan; open the disclosure before querying their accessible roles. Completion text is scoped to Team setup progress because the same outcome also appears in the toolbar notice.
