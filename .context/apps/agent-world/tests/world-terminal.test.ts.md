This suite loads the actual built Workplace, Ghostty canvas and Monaco editor. Terminal and workspace APIs are in-memory fixtures; it starts no shell, runtime or external process beyond its isolated browser. The terminal fixture synchronously emits ANSI output during create, before returning the session reply, and records subscriber count at that boundary. The renderer must subscribe first and retain that early output. A separate startup case emits CSI6n and holds the create reply: the actual renderer must send its cursor-position response before that reply resolves, while queries delivered after exit must not write. This distinguishes receiving initial text from completing terminal-protocol negotiation. Create returns a canonical cwd different from the seed root so tab identity cannot be confused with the currently selected repository.

Keyboard proof observes bytes passed through the public TerminalApi, not library internals. A before/after canvas screenshot comparison checks that delivered output changes visible pixels while focus and viewport stay unchanged; the current terminal uses a non-blinking cursor. The canvas has no ordinary DOM text content, so text locators are not output assertions. Inspect the saved screenshots to verify the early banner's text, colors and legibility; pixel change alone cannot prove those details. The approved terminal palette is fixed dark in both app appearances because ghostty-web 0.4.0 cannot safely update live core defaults. Check a terminal created in light appearance, the same terminal after an app-theme switch, and one created in dark appearance: the fixture's blank interior cell at the canvas center matches the fixed host background. The app switch must preserve the session, output and PTY input trace; there is no color synchronization or terminal recreation. Avoid the bottom/right fringe outside the cell grid: build55 changed that fringe while actual terminal cells stayed white, producing a false-positive sample that screenshot inspection exposed. Build54 passed keyboard/output cases but its dark screenshot retained a white canvas, so canvas presence and changed pixels alone are insufficient palette proof. The suite makes no OS clipboard, IME, physical trackpad, native PTY or durable cleanup claim; native backend tests own process behavior.

Hiding the terminal body leaves its header and sessions mounted. Switching apps or repository roots retains the session's initial root; a new terminal uses the new selected root. World is a retained rail tab with a lazy iframe, not a top-level navigation. The fixture opens the real World canvas and returns to both the same terminal and unsaved Monaco buffer. Exited tabs remain visible for inspection but stop input and release the live-shell unload guard. Close removes the tab and canvas. Repeated idempotent close calls from explicit closure and component cleanup are not duplicate shell creation.

Measure central-dock geometry against both Files and Source control sidebars, not only the containing Code pane. Opening the terminal must reduce the editor's available height while leaving both sidebar bounds unchanged. Viewport resizing exercises positive visible-only terminal dimensions; the initial dock has no drag splitter. The unload case checks a real native beforeunload dismissal on explicit full reload, alongside dispatching a cancelable event to isolate live-count changes from unrelated dirty editor drafts. Returning to retained World is deliberately outside this unload path.
