Why: issue selection is a read, delegation is a local instruction, and a Jira transition is an external write with a described intent/token confirmation. Keeping their traces separate proves that browsing and drafting cannot silently dispatch work or write to Jira. An applied instruction receipt means received, not task completed. Backend authorization, token consumption and persistence remain separate proof.
