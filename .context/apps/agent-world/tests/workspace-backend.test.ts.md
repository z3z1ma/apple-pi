## file

All filesystem and Git mutation is isolated under a temporary repository; these tests never edit a real project or connect to session-state. The partial node:fs mock wraps fsyncSync to schedule a real source-file replacement between temporary write and final save validation, and readFileSync/readdirSync to verify reference decoration reads neither file contents nor directory entries. Spying directly on the native ESM namespace is unsupported. The production implementation has no test-only callback.

Coverage checks nested lazy entries, BOM/CRLF text preservation, returned save hash, executable mode retention, stale/intervening-save refusal without visible directory debris, path/symlink/metadata/binary refusal, literal bracket filenames in Git diffs, Git staged/unstaged/untracked/rename/detached semantics and unchanged index, manual-subdirectory refusal, discovery and public IPC payload shapes. It does not prove real Electron IPC/preload, native unload confirmation, browser drafts, or protection against an external write in the final check/rename race.
Why: cleanup is observable through the public tree, not an internal temporary filename convention. Brackets in the real Git filename distinguish literal path handling from an accidentally expanded pathspec; an ordinary filename would pass both implementations.
Discovery cases create actual temporary linked and bare Git worktrees. They test selected-subdirectory path bases, tracked files despite ignore rules, ignored untracked omission, deleted-file and symlink-escape exclusion, plain-folder recursion, newline/Unicode paths and lock reasons, empty lock reason, missing/prunable roots, detached versus bare, and unchanged index bytes. These tests do not prove Quick Open filtering, root-switch draft preservation or built IPC wiring.
Reference cases distinguish explicit source cwd from unknown/stale context, absolute other-root files, contained parent segments, escaping leaf/directory symlinks, metadata aliases, FIFOs, canonical target output, literal colon and Unicode filenames, and isolated HOME expansion. A symlink source cwd plus macOS's /var alias exposed a root-selection defect that raw/canonical string prefixes missed; canonical ancestor selection keeps that escape refused. Binary and invalid UTF-8 files can be decorated without reading them; explicit later reads can fail for content or disappearance. Parser location priority, provenance selection and Electron forwarding are separate lanes.
